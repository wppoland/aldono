# Add-Ons – Product Options for WooCommerce

Add-Ons lets store owners offer extra product options that customers choose before adding a product to the cart — gift wrapping, engraving text, an extended warranty, a colour choice and more.

## Features

- Per-product add-ons defined in the WooCommerce product editor, each with a label, field type, optional required flag and optional price.
- Field types: plain text, checkbox, or select drop-down.
- Price deltas added to the cart line total automatically; leave the price at zero for free options.
- Customer choices shown in the cart, at checkout, and on the order.
- Display settings for the group heading, option prices, the required-field asterisk and a bordered card style.
- Definitions stored as standard product meta — no custom database tables.

## Installation

1. Upload the plugin to `/wp-content/plugins/addons`, or install it via Plugins → Add New.
2. Activate it. WooCommerce must be active.
3. Edit a product, open the **Add-Ons** tab in the Product data panel, and add your options.

## Frequently Asked Questions

**Does it require WooCommerce?**
Yes. WooCommerce must be installed and active.

**Does it create custom database tables?**
No. Add-on definitions are stored as product meta.
